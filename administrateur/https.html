    HTTPS¶

    Le certificat est obligatoire : sans lui, l'application n'est pas joignable et le micro est refusé par le navigateur.

    Vous n'avez rien à faire chez un fournisseur de noms de domaine. Le domaine kauze.tech et son jeton d'API sont tenus par l'éditeur, qui vous transmet le jeton.

    Poser le certificat¶

    Ce qu'il faut faire¶

    1. Demandez le jeton deSEC à l'éditeur.

    2. Écrivez-le sur le serveur, lisible par son propriétaire seulement :

      mkdir -p ~/.cause/letsencrypt
cat > ~/.cause/letsencrypt/desec.ini << 'EOF'
dns_desec_token = VOTRE_JETON
EOF
chmod 600 ~/.cause/letsencrypt/desec.ini

    3. Relancez le script d'installation, voir Relancer le script. La longue pause après Requesting a certificate dure dix minutes : c'est normal, ne l'interrompez pas.

    4. Redémarrez le frontend :

      docker compose restart frontend

    Vérifier¶

    ls ~/.cause/certs/
curl -sI https://$(grep '^KAUZE_DOMAINE=' ~/.cause/.env | cut -d= -f2)/ | head -1

    Le dossier doit contenir fullchain.pem, privkey.pem et https.conf, et la requête répondre HTTP/2 200.

    Si ça coince¶

    Dépannage.

    Changer le nom du site¶

    Ce qu'il faut faire¶

    1. Changez la ligne KAUZE_DOMAINE de ~/.cause/.env, par exemple chu.kauze.tech.
    2. Prévenez l'éditeur : le nouveau nom doit exister dans la zone.

    3. Appliquez et réémettez le certificat :

      docker compose up -d

    puis relancez le script d'installation, voir Relancer le script.

    Vérifier¶

    docker compose exec frontend grep server_name /etc/nginx/conf.d/https.conf

    La réponse doit porter le nouveau nom.

    Si ça coince¶

    Dépannage.

    Renouveler le certificat¶

    Ce qu'il faut faire¶

    Rien : un minuteur systemd s'en charge deux fois par jour. Laissez simplement le serveur allumé et connecté à Internet au moins une fois par mois.

    Vérifier¶

    systemctl list-timers cause-cert-renew.timer
openssl x509 -enddate -noout -in ~/.cause/certs/fullchain.pem

    Le minuteur doit être listé avec sa prochaine échéance, et la date de fin du certificat être à plus de trente jours.

    Si ça coince¶

    Dépannage.
