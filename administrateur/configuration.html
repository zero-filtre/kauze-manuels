    Configuration¶

    Tout se règle par des variables, dans un fichier qui vous appartient : ~/.cause/.env.backend.overrides. L'installation le crée et ne l'écrase jamais.

    Régler l'application¶

    Ce qu'il faut faire¶

    1. Ouvrez le fichier :

      nano ~/.cause/.env.backend.overrides

    2. Écrivez un réglage par ligne : le nom, le signe égal, la valeur, sans espace autour du signe égal et sans guillemets.

      ASR_DICTATED_PROVIDER=whisper
OLLAMA_TEMPERATURE=0.2

    3. Redémarrez le backend :

      cd ~/.cause && docker compose up -d backend

    Pour retirer un réglage, effacez sa ligne ou mettez un dièse devant, puis redémarrez. Une ligne NOM= sans valeur n'est pas un retour au défaut : elle impose une valeur vide.

    Vérifier¶

    cd ~/.cause && docker compose exec backend printenv ASR_DICTATED_PROVIDER

    Le conteneur doit répondre la valeur que vous venez d'écrire.

    Si ça coince¶

    Dépannage.

    Poser le secret des sessions¶

    Ce qu'il faut faire¶

    1. Tirez une valeur longue et aléatoire :

      openssl rand -hex 32

    2. Écrivez-la dans votre fichier de réglages, puis redémarrez le backend :

      AUTH_JWT_SECRET=<valeur tirée>

    À faire dès l'installation, et avec une valeur propre à l'établissement.

    Vérifier¶

    cd ~/.cause && docker compose exec backend printenv AUTH_JWT_SECRET

    La valeur doit être la vôtre. Les sessions ouvertes avant le changement sont invalidées.

    Si ça coince¶

    Dépannage.

    Ce que le fichier de réglages ne change pas¶

    Le docker-compose fixe ces valeurs et elles passent avant les vôtres : SPRING_PROFILES_ACTIVE, WHISPER_URL, MEDICAL_RECORD_WHISPER_ENDPOINT, OLLAMA_URL, OLLAMA_MODEL et ENRICHMENT_ENABLED.

    Le modèle de langue et la version applicative se changent dans ~/.cause/.env, voir Relancer le script.

    Les fichiers d'environnement d'un serveur livré¶

    Quatre fichiers cohabitent dans ~/.cause/ et ne servent pas à la même chose.

    Fichier Ce qu'il porte Qui l'écrit
    .env La version applicative (CAUSE_VERSION), celle des moteurs (CAUSE_MOTEURS), le modèle actif (OLLAMA_MODEL), CAUSE_HOME, KAUZE_DOMAINE. Le disque de livraison. Le script n'y réécrit que CAUSE_HOME.
    .env.backend.overrides Vos réglages. Vous, et personne d'autre.
    .env.backend Ce que le script a généré, dont les clés du stockage de l'éditeur. N'y écrivez rien : il est réécrit à chaque passage. Le script.
    .env.ghcr Le jeton de lecture du registre, voir Le jeton du registre. Vous, au renouvellement du jeton.

    Les trois derniers peuvent porter des secrets : aucune sauvegarde ne les emporte.

    Variables principales¶

    Modèles¶

    Variable Défaut Effet
    OLLAMA_MODEL gemma4:12b Modèle utilisé pour les rapports. Se change dans ~/.cause/.env.
    OLLAMA_TEMPERATURE 0.1 Température de génération.
    LECTURE_MODEL gemma4:26b Modèle qui lit les photos du dossier papier (couverture, feuille des constantes). Le 12b n'y arrive pas. Vide, c'est OLLAMA_MODEL qui lit, à condition qu'il voie les images. Se pose dans ~/.cause/.env.backend.overrides.
    LLM_PROVIDER ollama ollama, openai pour un service compatible OpenAI, ou airllm.
    OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL Groq, vide, llama-3.3-70b-versatile Fournisseur distant si LLM_PROVIDER=openai. Les données quittent alors le serveur.
    WHISPER_MODEL large-v3 Modèle de transcription.
    ASR_LIVE_PROVIDER whisper Moteur de transcription de la piste enregistrée au chevet du patient.
    ASR_DICTATED_PROVIDER whisper Moteur de transcription de la dictée du médecin, donc aussi des actes sans piste live.
    ASR_QWEN_URL vide Route du moteur Qwen3-ASR : http://qwen-asr:8998/v1/audio/transcriptions.
    REPORT_GENERATION_WORKERS 1 Générations simultanées. Ne dépasser 1 qu'avec un moteur qui le supporte.
    TRAINING_CORPUS_ENABLED true Fige l'audio et la transcription d'un rapport validé dans ~/.cause/corpus-entrainement/. Ce corpus contient de la voix de patients : mettre à false sans consentement de l'établissement.

    Enregistrement et rapports¶

    Variable Défaut Effet
    MEDICAL_RECORD_VISIBILITY_LOCK_TIMEOUT PT30M Durée du verrou de visibilité posé par un enregistrement.
    REPORT_GENERATION_MAX_WAIT_TIME_SECONDS 600 Attente maximale de la transcription avant de mettre le rapport en erreur.
    TRANSCRIPTION_THRESHOLD_MIN_LENGTH, TRANSCRIPTION_THRESHOLD_MIN_WORD_COUNT 100, 20 En dessous, le rapport est un template vide.
    MEDICAL_RECORD_RECORDING_FLOW_GOLDEN_RULES_CONSULTATION_THRESHOLD 3 Les règles d'or s'affichent tant que le médecin a moins de N consultations.
    SEGMENT_EDITING_ENABLED false Autorise l'édition manuelle du texte d'une portion de transcription.

    Stockage et purges¶

    Variable Défaut Effet
    MEDICAL_RECORD_STORAGE_CLEANUP_AFTER_HOURS 24 Âge des fichiers audio orphelins supprimés.
    MEDICAL_RECORD_STORAGE_CLEANUP_CHECK_INTERVAL 3600000 Cadence des purges, en millisecondes.
    MEDICAL_RECORD_STORAGE_STALE_WAITING_HOURS 48 Suppression des consultations créées mais jamais démarrées.
    MEDICAL_RECORD_STORAGE_MAX_FILE_SIZE 500 Mo Taille maximale d'un envoi audio, alignée avec nginx.
    CAUSE_PHOTOS_DIR ~/.cause/photos Dossier des photos du dossier papier, remises droites et rangées en JPEG sous leur identifiant. Se pose dans ~/.cause/.env.backend.overrides.

    Glossaire et apprentissage¶

    Variable Défaut Effet
    GLOSSARY_ENABLED true Injection du glossaire médical dans le prompt.
    GLOSSARY_MAX_ENTRIES, GLOSSARY_MIN_CONFIDENCE 5, 0.6 Nombre et seuil des entrées injectées.
    ASR_HARVEST_ENABLED true Apprentissage des corrections faites sur les rapports validés.
    ASR_HARVEST_THRESHOLD 3 Nombre de consultations où une correction doit apparaître avant d'être retenue.
    ASR_HARVEST_CRON toutes les heures Cadence du moissonnage.
    ENRICHMENT_ENABLED false Ancien pipeline d'enrichissement lexical, remplacé par le glossaire.

    Remontée des évaluations¶

    Active par défaut. Elle envoie une fois par mois vers le stockage de l'éditeur ce que la machine produit d'évaluations. Ce qui part et ce qui est retiré avant de partir sont dans Données et sauvegarde.

    Variable Défaut Effet
    REMONTEE_ENABLED true À false, rien n'est tenté et rien n'est journalisé.
    REMONTEE_BUCKET kauze Seau de l'éditeur. Vous n'avez pas à le changer.
    REMONTEE_ENDPOINT https://s3.gra.io.cloud.ovh.net/ Racine du stockage de l'éditeur.
    REMONTEE_REGION gra Région de signature.
    REMONTEE_ACCESS_KEY_ID, REMONTEE_SECRET_KEY vides Clés d'accès. Le script d'installation vous les demande.
    REMONTEE_INSTALLATION vide Préfixe qui sépare votre établissement des autres. Le script y met le numéro de licence.
    REMONTEE_DIR ~/.cause/remontee File d'attente sur disque et registre des envois réussis.
    REMONTEE_CRON le 1er du mois à 2 h 30 Construction de la file.
    REMONTEE_RETRY_CRON toutes les cinq minutes Reprise des envois en attente, jusqu'au succès.
    REMONTEE_BATCH 50 Objets au plus par passage de reprise.
    REMONTEE_MAX_FILE_BYTES 1 Go Au-delà, un fichier n'entre pas dans la file.
    REMONTEE_SOURCE_BASELINE ~/.cause/baseline-diagnostic Dossier lu pour la catégorie baseline.
    REMONTEE_SOURCE_CHARGE ~/.cause/mesure-charge Dossier lu pour la catégorie charge.
    REMONTEE_SOURCE_CORPUS ~/.cause/corpus-entrainement Dossier lu pour la catégorie corpus.

    Une machine sans ses clés n'est pas en erreur : la file se remplit et les envois partiront dès que les clés seront posées. Relancer le script les redemande tant qu'elles manquent.

    Sécurité¶

    Variable Défaut Effet
    AUTH_JWT_SECRET à poser Secret de signature des sessions, propre à chaque installation.
    AUTH_TOKEN_EXPIRATION_HOURS 24 Durée de validité d'une session.
    SPRINGDOC_ENABLED false en prod Active Swagger. Ces pages sont publiques quand elles sont activées.

    L'inscription publique reste ouverte : toute personne qui joint le serveur peut se créer un compte infirmier ou médecin. Seul le rôle ADMIN y est refusé. Sur un réseau partagé, limitez l'accès au serveur au niveau du réseau.

    Hôte et script¶

    Variable Défaut Effet
    CAUSE_HOME ~/.cause Racine des données, figée dans .env par le script.
    CAUSE_VERSION la version livrée Étiquette des images du backend et du frontend. C'est la ligne que change une mise à jour.
    CAUSE_MOTEURS la version du disque Étiquette des images des moteurs, qui ne change qu'avec un nouveau disque.
    KAUZE_DOMAINE le nom du site Nom pour lequel nginx redirige et le certificat est émis, voir HTTPS.
    CAUSE_NO_HOTSPOT non défini Passe l'installation du hotspot Wi-Fi.
    CAUSE_NO_UPDATE_LOCK non défini Laisse les mises à jour du système libres : pour un poste de développement, jamais pour un serveur livré.
    CAUSE_WIFI_IFACE détection Force l'interface Wi-Fi du hotspot.
    CAUSE_HOTSPOT_COUPE_MA_SESSION non défini Lève le refus de reprendre l'interface qui porte votre session, voir Hotspot Wi-Fi.
    CAUSE_SANS_QUESTIONS non défini Installation en série : le script ne pose aucune question.
    CAUSE_AVEC_TEST_AUDIO non défini Installe la banque audio de mesure du disque dans ~/.cause/test-audio.

    La vérification de licence, elle, ne se configure pas : aucune variable ne l'atteint. Voir La licence machine.
